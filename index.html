💾 备份 / 恢复配置

点「复制」把配置发给小助手，可永久固化进应用；把新的配置 JSON 粘贴进来后点「导入」即可恢复。本地选择的演示视频/动图只存本机、不随备份导出；在线链接和训练记录（最近 500 条）会包含在备份中。

❤️ 导入 Apple 健康

把「健康」里的训练（时长 / 心率 / 消耗 / 距离）导进来，会自动与训练记录按时间合并；健康里有、应用里没有的训练会新增成记录。
不用快捷指令，直接导入（推荐）：
① 健康 App → 右上角头像 → 最底下「导出所有健康数据」→ 确认 → 等几分钟（数据多年会慢）
② 选「存储到文件」，保存到「文件」App
③ 回到这里点上方按钮，选那个 导出.zip 即可
需先用快捷指令把数据放进剪贴板（设置一次，见下）。在主屏应用里也能用，因为剪贴板是系统级共享的。
📖 不会建快捷指令？看一步一步图文 ▾

目标：建一个「健康同步」快捷指令，练完把它生成的文本放进剪贴板，再回本应用点「一键导入」。

  1. 打开「快捷指令」App → 右上角 ＋ → 新建空白快捷指令。
  2. 加「查找所有健康样本」（也叫「获取健康样本」）：类型选 体能训练，过滤「开始日期 是 今天」，排序 最新在前，限制 1。
  3. 加「获取详细信息」（来自上一步的体能训练）：勾 开始日期、结束日期、时长、活动能量、总距离（有就勾）。
  4. 加「文本」：先点下面「复制 JSON 模板」粘进去，再点文本框里的 变量 按钮，把模板里的 开始日期 等占位换成第 3 步的「详细信息」输出。
  5. 加「拷贝到剪贴板」，把文本放进去。命名「健康同步」保存。

想要心率：在第 3 步前再加「查找所有健康样本（类型 心率，开始/结束用上面两个日期）」+「计算统计信息（平均值）」，把结果填到模板的 hr。

全自动（可选）：快捷指令 → 自动化 → 体能训练 → 结束时 → 运行「健康同步」→ 关「运行前询问」。练完自动放剪贴板，你只需回应用点一下「一键导入」。

⚠️ 别在快捷指令里用「打开 URL」：主屏应用和 Safari 存储隔离，那样数据会进 Safari，你在主屏应用里看不到。
③ 完全零点击（仅 Safari 标签页，主屏应用不生效） ▾
把上面第 5 步换成「URL 编码」+「打开 URL」：
https://wanggood88.github.io/fitness/#hi=编码后的文本&auto=1
这样练完会自动打开页面并直接导入，无需点按。
注意：iPhone 主屏应用的存储与 Safari 完全隔离，这种方式只在 Safari 标签页里生效；装在主屏的话请用「一键导入」。
